# Claude Instructions

Please refer to `@AGENTS.md` for project information.

## Claude-specific Rules

Using Claude or Claude Code for development is allowed.

However, this repository does not recognize Anthropic Claude, Claude Code, or related bot identities as valid Git authors or co-authors.

Do not submit commits, pull requests, commit trailers, or any Git metadata that attributes work to Anthropic Claude, Claude Code, or identities such as `noreply@anthropic.com`.

AI-assisted work is still the responsibility of the human contributor. Contributions should be attributed to the person submitting and maintaining the work, not to a tool used during development.

Before creating commits or pull requests, make sure Claude Code Git attribution is disabled.

If you do not know how to disable Claude Code Git attribution, ask your operator or refer to the Claude Code documentation before making any commits.
